游戏自动化精简版

已修复：
1. 同盟首页进入“同盟礼物”改为模板定位 + 多候选点击 + 页面确认，点击失败会自动重试。
2. 礼物页不再假定固定的初始 Tab：先识别当前高亮的“同盟送礼”或“同盟礼物宝箱”，再处理另一个 Tab。
3. 两个 Tab 内的绿色“领取”按钮会按从上到下逐个扫描；宝箱页底部的绿色“一键领取”也会在确认可用后处理。
4. 领取结束后只返回“同盟”主页，不会误退回主城。
5. 体力“获取更多”页面按当前仓库列表位置重新采集绿色“领取”模板，并扩大识别区域。
6. 日常任务入口增加左下角固定区域的安全重试，只有确认进入日常任务页才继续点击。
7. 爵位入口改为点击左上角“权”金色徽章，并增加页面确认后的徽章邻近坐标重试。

运行前：
1. 修改 config.json 中的 adb_path、scrcpy_server_path 和 device_serial。
2. 手动打开游戏并保持在可识别页面。
3. 在 game_auto_v1 目录运行：
   python game_auto_v1_17.py --live --task alliance

完整任务：
   python game_auto_v1_17.py --live --task all

不加 --live 时只识别当前页面，不执行点击。
运行产生的日志、每日状态和失败截图会自动写入 runtime/，不放入发布压缩包。

本版另已修复同盟礼物宝箱/同盟送礼两个页签的点击位置、动态高亮判断与切换确认。
